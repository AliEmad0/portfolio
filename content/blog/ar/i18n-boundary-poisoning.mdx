أنتج PitchIQ مرة **٥٤١ واجهة إنجليزية بين ٩٤٠ تصييرًا عربيًا**، بينما ظل كل مستند يحمل `lang="ar" dir="rtl"`. لم تكن المشكلة رسالة ناقصة، بل حسم إعداد الطلب مبكرًا وتخزينه لبقية التصيير.

## السبب: حد لا يملك معاملات اللغة

لا تستقبل ملفات `not-found.tsx` و`error.tsx` و`loading.tsx` و`template.tsx` معاملات المسار. ومع ذلك استدعى حد على الخادم API من next-intl:

```tsx
// غير آمن: لا توجد لغة لتمريرها إلى إعداد الطلب.
export default async function NotFound() {
  const t = await getTranslations('errors');
  return <h1>{t('notFound')}</h1>;
}
```

اختارت المكتبة القاموس الإنجليزي الافتراضي وخزنته. ولأن Next يصيّر الحد ضمن غلاف المقطع، وقع القرار قبل اكتمال الصفحة العربية والتخطيط المشترك.

يستهلك الحد الآمن اللغة التي ثبتها المزوّد:

```tsx
'use client';

export default function NotFound() {
  const t = useTranslations('errors');
  return <h1>{t('notFound')}</h1>;
}
```

يرفض فحص مصدري الآن APIs الخادم الخاصة بالترجمة داخل الحدود التي لا تملك معاملات.

## لماذا كذبت الاختبارات الأولى؟

بقيت هذه الفحوص خضراء:

- جاء `<html lang="ar" dir="rtl">` من معاملات المسار لا القاموس.
- جاءت أسماء اللاعبين العربية من محمّل مستقل بمعامل صريح.
- وجد البحث نصًا عربيًا لأن next-intl يضمّن القاموس كاملًا.
- نجح اختبار البيانات العربية داخل واجهة إنجليزية.

الاختبار المفيد يفحص الناتج المرئي:

```ts
expect(screen.getByRole('heading')).toHaveTextContent('الصفحة غير موجودة');
expect((html.match(/[؀-ۿ]/g) ?? []).length).toBeGreaterThan(20);
```

## RTL ليس مرآة لكل شيء

يجب أن يستخدم النص الخصائص المنطقية:

```css
.card {
  padding-inline-start: 1rem;
  border-inline-end: 1px solid var(--line);
}
```

لكن ملعب كرة القدم هندسة مادية لا نص. عكس مواقع اللاعبين مع بقاء المرميين يمينًا ويسارًا وضع الحارس في الوسط. لذلك يخرج الملعب من RTL:

```tsx
<div className="pitch" dir="ltr" />
```

يفحص الاختبار اتجاه الحاوية، لا قيم `insetInlineStart` المتطابقة التي لا تكشف المشكلة.

## الأرقام والأسماء تحتاج سلوك Unicode صريحًا

أعاد المتصفح أرقامًا غربية من `Intl.NumberFormat('ar')`، كما حوّل قصر الاسم على `[A-Za-z]` الاسم العربي إلى نص فارغ.

```ts
const EASTERN = ['٠', '١', '٢', '٣', '٤', '٥', '٦', '٧', '٨', '٩'];

export function localizeDigits(value: string) {
  return value.replace(/\d/g, (digit) => EASTERN[Number(digit)]);
}

export function scoreboardName(name: string) {
  return /[؀-ۿ]/.test(name) ? name : abbreviateLatinName(name);
}
```

يحتاج النص المرسوم على Canvas إلى المساعد نفسه؛ لا تنتهي الترجمة عند عناصر React.

## استراتيجية منع الانحدار

تتحقق حزمة موثوقة من أربعة عقود منفصلة:

1. لغة المسار واتجاه المستند؛
2. قاموس الرسائل المرئي؛
3. بيانات الكيان المختارة للغة؛
4. المكونات المادية التي تبقى LTR عمدًا.

الدرس أن بيانات اللغة وترجمة الرسائل والبيانات المحلية والهندسة أنظمة مستقلة. اختبار أحدها لا يثبت الثلاثة الأخرى.
